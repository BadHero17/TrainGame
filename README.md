  A small OpenGL game about trains. Control the train to the nearest resource stations, grab the resources,
return back to the main stations to deliver within the time limit. Get scored based on remaining time, infinite gamemode,
target is to get as high a score as possible.

  Features full procedural generation of the terrain, and random generation of the placements of stations and railways.

  To run, clone the repo, then run gfx-framework\build\bin\Debug\GFXFramework.exe

  Credits to the UPB Graphical team for the public framework, available for download at https://ocw.cs.pub.ro/courses/egc/setup-framework
